What this site is

A chapter-based, hands-on path to designing gRPC APIs well, built around a single Protocol Buffers contract — linted and breaking-change-gated by Buf — for a shipping and cargo domain. gRPC here is the internal, latency-sensitive routing and tracking service that the sibling REST booking service calls. Every hands-on chapter ships the same example in both Quarkus and Python, generated from that one proto, and CI asserts each response against it — an OK that carries a contract-violating message fails the build. You work through the four RPC types, deadlines and the rich error model, schema evolution, backend concurrency, streaming and backpressure, performance tuning, security, observability, the Kubernetes load-balancing problem, gRPC-Web and transcoding. It assumes you can read Java and Python; it is not a tutorial in either language. The code tabs are built to admit Go and C++ later. All container images are UBI-based, and the stack runs on Docker Compose, minikube, and OpenShift Local.
