This site's chapter arc, pattern coverage, and level of rigor draw on a small set
of books and primary docs on gRPC, Protocol Buffers, and distributed systems.
They're reference works, not sources — no text or code from any of them is
reproduced here. If a topic in this site is useful to you, these are where to go
deeper.

| Title | Author(s) | Publisher | Focus |
|---|---|---|---|
| [*gRPC Microservices in Go*](https://www.packtpub.com/en-us/product/grpc-microservices-in-go-9781484299968) | Hüseyin Babal | Packt | Performance, scaling, worked service patterns |
| [*gRPC Go for Professionals*](https://www.packtpub.com/en-us/product/grpc-go-for-professionals-9781837638840) | Clément Jean | Packt | Protobuf language, schema design, evolution |
| [*Building Microservices*, 2nd ed.](https://www.oreilly.com/library/view/building-microservices-2nd/9781492034018/) | Sam Newman | O'Reilly | Resilient distributed systems, inter-service calls |
| [grpc.io documentation](https://grpc.io/docs/) | gRPC authors (CNCF) | — | Canonical RPC / channel / deadline / error reference |
| [Cloud Native Design Patterns](https://patterncatalyst.github.io/cloud-native-design-patterns/) (gRPC sections) | PatternCatalyst | — | Paradigms, stub-to-stub, why gRPC is fast, versioning, errors |
| [Quarkus gRPC guides](https://quarkus.io/guides/grpc) ([reference](https://quarkus.io/guides/grpc-reference)) | Quarkus | Red Hat | `quarkus-grpc` specifics (re-verified against current Quarkus) |

These titles inform this site's coverage and rigor only — nothing in these chapters
or the runnable examples copies text or code from them.
